# Janmejay Pandya's Portfolio

A modern, high-performance portfolio website showcasing projects, experience, and skills.

## 🌐 Live Website
Check it out here: [janmejaypandya.in](https://janmejaypandya.in)

## 🚀 Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Routing:** React Router DOM

## 🛠️ Key Features
- Fully responsive design for mobile and desktop.
- Project archives with detailed views.
- Interactive components with fluid animations.
- Dedicated sections for Experience, Skills, and Contact.

## 📦 Installation & Setup
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
